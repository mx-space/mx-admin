所验： ① 图非 widget，乃序文之佐图 ——「你这周写了 4 篇 [sparkline]」，数皆有所云，非冷裸数字； ② palette 入纸调 —— bars/lines 用 #6b5840(墨)、#a89568(matte gold)，accent 一处即可，无 SaaS 之蓝紫； ③ donut/pie 用四阶 sepia 同色不同明，legend 文字 italic； ④ tag cloud → italic words，字号即权重，无 cloud lib 之乱； ⑤ /analyze 之深表 —— filter 同「showing X · past 30 days · by day」单行下划线语，bar chart 横展长条，峰值染暗墨 + italic 序文 "↑ rewrite essay · May 12" 注其下，非 tooltip； ⑥ G2 仍可用，但 theme override 必加 —— accent / axis / label 皆吐 token 用纸色； ⑦ 与「夜灯」夜模同此 —— 工坊深色变 backup，色 ramp 仅明暗，accent 仍油焰金。
