所验： ① 无 sidebar 可折——desktop 本无 nav，移动反不必处理 nav 之坍缩。唯顶一行 "斋 · 室名 ▾"，▾ 触即弹小 sheet 列六室。 ② 主从三栏 → list + drawer-overlay（spec 11 batch 3a 之要）：架子之 inspector / 友人之细看，皆从右滑入，左留 14px 露 list 一线（fingerable back）； ③ ⌘K → ⌘ icon 于顶右；亦可页中下拉手势触 find； ④ letterpress 操作带仍底浮（不浮屏内悬空之 button），有选始现，文字小排，esc 即 swipe-down； ⑤ 写字台 agent panel + envelope 皆变底 tab：左 "envelope ▴" 上推弹 metadata，右 "apprentice · 2 notes" 推弹边注 sheet； ⑥ 偏好册 TOC 化作顶左 "≡ chapters" tap → 全屏目录 sheet（罗马序 i-ix）； ⑦ charts 自然单列重排——sparkline 满宽，bar chart 宽展，donut 缩小，tag cloud 字号比例不变； ⑧ 工坊 monaco 之代码：横向滚动 + soft wrap toggle（顶 chrome 一字）；xterm 同 width，font-size↓。
